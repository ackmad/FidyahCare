# Fidyah Care — Design System v2.0

## 1. Design Direction
Modern Islamic × Clean × Friendly × Trustworthy × Calm.

## 2. Visual Principles
- Off-white / white base.
- Emerald / forest green accent.
- Charcoal text.
- Subtle cream/gold accent.
- Generous whitespace.
- Rounded but restrained components.
- Clear hierarchy.
- Mobile-first.
- Avoid visual overload.

## 3. Typography
Prioritize readable modern sans-serif typography.
Use clear hierarchy for:
- Page title
- Question
- Result
- Explanation
- Source
- Secondary metadata

## 4. Important UI States

### Verified Result
Clear result with source indicator.

### Ikhtilaf
Label:
"Ada perbedaan pendapat ulama"

### Framework Required
Label:
"Hasil bergantung pada pendapat/mazhab yang digunakan"

### Review Required
Label:
"Kondisi ini cukup khusus. Fidyah Care tidak menyimpulkan secara otomatis."

### Insufficient Evidence
Label:
"Dasar yang tersedia belum cukup untuk memberikan jawaban otomatis."

### Need More Information
Ask only the missing question.

## 5. Accessibility
- Strong text/background contrast.
- Large touch targets.
- Avoid relying on color alone.
- Clear labels for icons.
- Readable Arabic text and translations.

## 6. Motion
Animations should be subtle, fast, and functional.
No animation should obscure religious source content or slow the flow.
