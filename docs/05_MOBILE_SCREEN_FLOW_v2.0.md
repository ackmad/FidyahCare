## 4. Result Screen
Must contain:
1. Ringkasan kondisi
2. Apa yang sebaiknya dilakukan?
3. Qadha/fidyah status
4. Important caveat
5. Dasar hukum
6. Source references
7. Optional calculator CTA

## 5. Source Detail
Show:
- source title
- source type
- source ID
- relevant reference
- external link when available
- role of source in the rule

## 6. UX Safety
Never present a framework-specific opinion as universal.
Never hide disagreement.
Never fabricate certainty.

## 7. Example Adaptive Question
For pregnancy/breastfeeding:
"Apakah kekhawatiran utama Anda terhadap diri sendiri, bayi, atau keduanya?"

Options:
- Diri sendiri
- Bayi
- Diri sendiri dan bayi
- Tidak yakin

If uncertain:
→ explain limitation
→ ask only relevant follow-up or route to review.
