# RULE-02 — Sakit Kronis / Tidak Diharapkan Pulih

Status: GREEN — FINAL VERIFIED, FRAMEWORK-SPECIFIC

## Scope
A person is genuinely unable to fast and the condition is not reasonably expected to improve enough to permit qadha.

## Rule
Within the documented framework:
- FIDYAH = applicable.
- QADHA = not required while the inability is permanent/continuing with no realistic recovery.

## Basis
- SRC-QURAN-001
- SRC-MUI-001
- SRC-BAZNAS-001

## Guardrail
A disease name alone is never enough. The application must not diagnose or predict prognosis. Use wording such as "jika secara nyata tidak mampu dan tidak diharapkan mampu mengganti kemudian."

If recovery later becomes realistically possible, the user should reassess the qadha obligation.
