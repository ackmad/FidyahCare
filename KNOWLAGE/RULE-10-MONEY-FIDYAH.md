# RULE-10 — Fidyah dengan Uang

Status: GREEN — VERIFIED, FRAMEWORK-SPECIFIC

## Principle
Do not present monetary fidyah as universally agreed.

## Documented positions
NU Online explains that the majority position differs from the Hanafi position on paying fidyah by monetary value (qimah), while the Hanafi school permits monetary valuation under its conditions:
- SRC-NU-001.

## Institutional operational reference
BAZNAS RI has a 2026 monetary fidyah reference of Rp65,000/day in its own distribution framework:
- SRC-BAZNAS-002
- SRC-BAZNAS-003.

## Application behavior
If user selects a framework/institution that permits or provides a monetary amount:
show:
- framework/institution name;
- year;
- amount;
- number of days;
- total;
- source.

Never display:
"Fidyah Islam = Rp65,000/day."

Display:
"Reference BAZNAS RI 2026 = Rp65,000/day."

If no framework is selected:
show food-unit calculation and explain that monetary payment has scholarly disagreement.

## No payment processing
MVP only calculates/educates; it does not process real payments.
