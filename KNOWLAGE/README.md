Status: FINAL SOURCE-VERIFIED for the documented MVP scope.

## Meaning of GREEN
GREEN means the content has a verified source basis and an explicitly documented scope/framework. GREEN does **not** mean:
- every scholar agrees;
- every case can be resolved automatically;
- the app is issuing a fatwa.

For framework-dependent or complex cases, GREEN means the knowledge is verified while the application may require framework selection, transparent ikhtilaf display, or human review.

## Source hierarchy
1. Al-Qur'an
2. Hadis Nabi ﷺ
3. Atsar Sahabat
4. Tafsir / Syarah
5. Fiqh / Mazhab / scholarly discussion
6. Institutional guidance (MUI, Kemenag, BAZNAS, NU) as supporting/framework sources
7. Application rule

Institutional sources never replace primary revelation.

Sederhanakan cara menjelaskan, bukan sederhanakan sumber hukumnya.

## Important boundary
The application must not diagnose illness, infer prognosis, determine a user's madhhab, or invent a legal ruling. When the documented framework is insufficient, return REVIEW_REQUIRED rather than guessing.
